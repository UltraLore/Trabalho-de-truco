Os arquivos a seguir sao de um trabalho da universidade para montar um jogo de truco em grupo, 
utilizando a linguagem de programação C

Como esta versão é um protótipo ela ainda não tem todas as mecânicas de truco, basicamente ela
é mais um jogo simples de cartas com alguns elementos do truco (como a seleção da manilha e
o sistema de ranking entre as cartas que mudam com a manilha)
